## [1.2.0] - 2026-11-15

**The final Rust release**, and the oracle for the Cyrius port (`docs/development/soorat-port-plan.md`, D1 and D2). It is a minor release because it adds public API: `PostProcessPipeline::set_bloom`/`clear_bloom`, `PostProcessUniforms::with_bloom_intensity` and the hidden `oracle` feature.

### Added
- **oracle** (hidden, non-default `oracle` feature): read-only hooks for the Cyrius port's golden-value generator (`docs/development/soorat-port-plan.md`, D1). They expose the crate-private helpers behind the public API: `math_util` and `viz`; animation's keyframe bracket, interpolation, slerp, sampler pairing and joint transforms; environment's sRGB/f16 conversions, sRGB decode table, face encode/decode, downsample and mip chain; the shadow atlas tile math; and the mesh normal matrix. **Not public API**: the module is `#[doc(hidden)]`, carries no stability promise and is not part of `full`. `tests/oracle.rs` (18 tests) checks that each hook agrees with the public path it backs, and that calling the hooks changes no public output.
- **postprocess**: `PostProcessPipeline::set_bloom` and `clear_bloom`, and `PostProcessUniforms::with_bloom_intensity`. They make the bloom composite (`fs_main` and bind group 1) reachable; see Fixed.
- 22 new tests (479 → 501 with all features): 18 oracle-hook tests, 2 GPU regression tests (damping, bloom) and 2 unit tests (bloom intensity, free surface). No benchmarked CPU path changed apart from the joint-matrix refactor (A/B under Changed).

### Changed
- `Skeleton::compute_joint_matrices` now goes through the extracted `animation::world_transforms` and `local_transform`, and environment maps build their mips through `face_mip_chain` and `srgb8_decode_table`. These are the same functions the oracle exposes. Output is unchanged, bit for bit. Speed is unchanged too: a same-machine A/B run of the old and new code, three alternating runs each, gave `compute_joints_16` 285–288 ns before and 275–286 ns after, `compute_joints_64` 1.10–1.18 µs before and 1.12–1.16 µs after, and `compute_joints_64_unsorted` 1.43–1.49 µs before and 1.42–1.49 µs after.

### Fixed
- The environment-map box downsample panicked on a zero size or a short input (unreachable from the public API, which validates both) → it returns an empty image.
- **Particle damping depended on the frame rate.** The compute shader multiplied velocity by `damping` once per step, so at 30 fps velocity decayed half as much per second as at 60 fps. `SimParams::damping` is now the factor per 1/60 s reference step, applied as `damping^(delta_time · 60)`, which is identical at 60 Hz. A GPU regression test fails on the old shader (x = 0.01667 against the expected 0.00833 at dt = 1/30).
- **Bloom was never composited.** `PostProcessPipeline` built only the `fs_no_bloom` entry point, so `BloomPipeline` output could not reach the image. Binding a bloom texture with `set_bloom` now switches to `fs_main`, which adds `bloom × intensity` before exposure and tone mapping. Without one, rendering is unchanged. A GPU test checks 0 → 0.5 → 0 as bloom is bound and cleared.

### Performance
- No performance change. The release run (2026-11-15T21:19Z) sits a median 7 % above the morning's final 1.1.0 run across all 35 benchmarks. That includes code untouched since then (`color/from_hex` +8 %, `shadow/directional_matrix` +10 %, `screenshot/encode_png_256` +15 %), so the shift is machine state, not code. The one benchmarked path this release touched (joint matrices) showed no difference in a same-machine A/B run (see Changed).

### Documentation
- **Known limitation, decided 2026-11-15:** glTF `CUBICSPLINE` samplers keep each key's value and drop its tangents, so playback between keys is linear (slerp for rotations). Values at key times are exact. A fix needs tangent storage in `Keyframe`/`AnimationChannel`, which would break their public struct literals, so Hermite interpolation lands in the Cyrius port (soorat 2.0, port plan ADR 0002 #13). `load_gltf_animations` documents this.
- `fluid_render::shallow_water_to_mesh`: pravash's `height` is the surface elevation η (depth is `height − ground`), so the mesh is already the free surface over any bathymetry. The 1.1.0 roadmap item "render `ground + height`" was wrong and is withdrawn; a regression test locks in the correct behaviour.

#### Behavior (2026-11 audit)
- **Visualization grids must be backed by their data** — a grid whose `product(dims)` exceeds its value count now yields an empty mesh (with a warning) instead of zero-filling, so output size stays proportional to input size.
- **Signed color modes are centred on zero** (`v / max|v|`) instead of on the data's midpoint — zero now always renders black (EM `Signed`, acoustic `SignedPressure`).
- **EM `Magnitude` mode colors `|v|`** (it colored the signed value, so −1 and +1 differed).
- **Field lines share one normalization** across all lines (weak lines no longer look as hot as strong ones).
- **Radiation patterns are looked up by azimuth φ** (bijli's NF2FF angles), with wrap-around, and the in-plane pattern fades toward the poles (previously looked up by polar θ, losing half the pattern).
- **Coupled decay curves fall** from 0 dB at `origin` (they rose as energy decayed).
- **Acoustic ray segments** are colored by the energy they carry (full energy to the first bounce).
- Shadow pass uses an explicit regular light view + `Face::Back` (same triangles rendered as before; the previous mirrored basis made `Face::Front` act as back-face culling).
- `RenderGraph::add_pass` with an existing name updates that pass instead of orphaning a duplicate.
- `SpriteBuffers` grow geometrically (×1.5) and cap at `MAX_SPRITES_PER_BATCH`.
- `DepthBuffer` textures are also `TEXTURE_BINDING` (sampleable, e.g. for SSAO).

### Fixed

#### Rendering correctness (2026-11 audit)
- **Normal matrix uploaded transposed** — `CameraUniforms::set_model` produced M⁻¹ instead of M⁻ᵀ, so rotated meshes were lit as if rotated the opposite way (a +X normal under a 90° Z rotation became −Y).
- **Environment-map mips were never written** — cubemaps allocated a full mip chain but uploaded only mip 0; wgpu zero-fills the rest, so specular IBL went black for roughness ≥ 0.25 and irradiance darkened when minified. Mip chains are now generated on the CPU (2×2 box filter in linear space, sRGB and f16 aware).
- **BRDF LUT uploaded as sRGB** — sampling decoded the linear scale/bias, making specular IBL 2–4× too dark; now `Rgba8Unorm` with a bilinear sampler.
- **Inward-facing meshes** (culled by back-face culling): `primitives::sphere`, cylinder caps, every viz heatmap (acoustic, EM 2D/3D, thermal), SPH particle quads, directivity and radiation balloons.
- **SSAO** reconstructed the centre pixel's view position with Y flipped.
- **Shadow lookups**: per-fragment perspective divide (perspective light matrices were wrong), `textureSampleCompareLevel` instead of `textureSampleCompare` after non-uniform early returns (rejected by WebGPU/Tint).
- **Skinned shader**: weights renormalized; tangents transformed by the model matrix and re-orthogonalized.
- **`SpritePipeline::draw_batched` overran its index buffer** for batches above 16,383 sprites (wgpu validation panic); now clamped and logged.
- **`WindowConfig::fullscreen` was ignored**.
- Sprite/line projection uniforms initialized to an all-zero matrix (documented as identity).

#### Animation (2026-11 audit)
- Rotation channels were lerped component-wise (non-unit quaternions shrank/sheared joints mid-blend) → shortest-path slerp.
- `STEP` and `CUBICSPLINE` samplers were ignored; cubic-spline outputs (3 per key) were paired with the wrong times.
- Channels targeting non-joint nodes animated joint 0.
- Joints listed before their parents (allowed by glTF) were treated as roots; cycles are now broken safely.
- Negative times wrapped incorrectly; NaN times produced NaN poses.

#### Robustness / untrusted input (2026-11 audit)
- glTF: unchecked `offset + length` for image buffer views; primitives with out-of-range indices (GPU out-of-bounds reads) or non-triangle modes are skipped.
- Textures larger than the device's `max_texture_dimension_2d` returned a wgpu validation panic → `RenderError::Texture`.
- Visualization: NaN/±inf samples panicked the heat map in debug builds (`Color::new` assert) or produced NaN colors; unbounded segment counts; unchecked grid products; stale/zero `max_magnitude` produced arrows up to 10¹⁶ long; thermal alpha outside [0, 1]; shallow-water meshes with NaN normals or panics on inconsistent public fields, and a dx/2 centring error.
- Zero-size `DepthBuffer`/`HdrFramebuffer`/`ShadowMap`/`ShadowAtlas`/`GpuParticleSystem` (e.g. minimized window) tripped wgpu validation → clamped to 1.
- `ShadowAtlas`/`tile_viewport`/`tile_uv` divided by zero when `tile_size > size`.
- Cascade splits produced NaN for `far ≤ 0` or NaN inputs.
- `GpuParticleSystem` read back past its buffer when `particle_count` exceeded capacity, and could exceed the dispatch limit.
- `UvRect::from_pixel_rect` / `BitmapFont::glyph_uv` integer overflow; terrain vertex-count overflow; terrain edge normals used a halved slope.
- `BloomPipeline::new` discarded the pipeline error (now logged).

#### Correctness (Sprint 1)
- **Eliminated all `expect()`/`assert_eq!()` in library code** — 15 panic sites across 8 files converted to `Result` propagation.
- **PBR specular denominator** — clamped entire `4.0 * NdotV * NdotL` denominator to prevent specular spikes at grazing angles.
- **Shadow coord z check** — objects behind shadow light now correctly marked as lit (`coords.z < 0.0`).
- **Animation parent-joint logic** — broken `any(|_| false)` replaced with correct parent search in glTF skeleton loading.
- **`from_ior()` dead parameter** — computed Fresnel reflectance (F0) now stored for shader access.

- **Division-by-zero guards** — `UvRect::from_pixel_rect`, `BloomUniforms::new`, `BitmapFont::glyph_uv`, cascade splits, terrain generation.
- **Checked integer casts** — `batch.rs` u16/u32 indices, `mesh_pipeline.rs` index count, `terrain.rs` saturating_add.
- **NaN guard** — `vector_field_to_arrows` now skips non-finite magnitudes.

#### Textures
- `Texture` — `from_bytes` (PNG/JPEG), `from_color`, `from_rgba`, `white_pixel`.
- `TextureCache` — single HashMap with `get_or_load()` lazy loading.
- `RenderTarget` / `RenderTargetBuilder` — offscreen framebuffer with `read_pixels()`.

#### 3D PBR Rendering
- `MeshPipeline` — PBR shader (Cook-Torrance/GGX/Fresnel-Schlick via prakash).
- Multi-light PBR — up to 8 lights (directional, point, spot) per draw call.
- `CameraUniforms` — view_proj, model, camera_pos, inverse-transpose normal matrix.
- `Mesh`, `Material`, `MaterialUniforms` — GPU vertex/index buffers, PBR material helpers.
- `SkinnedVertex3D` + `pbr_skinned.wgsl` — vertex skinning + tangent-space normal mapping.
- BRDF LUT precomputation via prakash (feature: `optics`).

#### glTF Loading
- `gltf_loader::load_model()` — zero-copy buffer borrowing, embedded textures.
- `animation::load_gltf_animations()` — skins, joints, animation channels.

#### Shadows
- `ShadowMap` + `ShadowPipeline` — depth-only pass, PCF 3x3 soft shadows.
- `CascadedShadowMap` — 1–4 cascades with practical split scheme.
- `ShadowAtlas` — single depth texture subdivided into tiles for multiple lights.
- `PointShadowMap` — 6-face cube shadow maps for point lights.

#### Lighting
- `GpuLight` — directional, point, and spot light types.
- `LightArrayUniforms` — up to 8 lights with ambient color.
- `EnvironmentMap` + `IblBindGroup` — image-based lighting.

#### Animation
- `Skeleton`, `Joint`, `AnimationClip`, `JointUniforms` — 128-joint skinned animation.

#### Debug Rendering
- `LinePipeline` + `LineBatch` — wireframe lines, shapes, grid, collider outlines.

#### Post-Processing
- `PostProcessPipeline` — Reinhard + ACES filmic tone mapping.
- `HdrFramebuffer` — Rgba16Float render target for linear HDR.
- `BloomPipeline` — threshold → separable 9-tap Gaussian blur (H/V passes).
- `SsaoPipeline` — screen-space ambient occlusion with hemisphere sampling.

#### World / UI / Text
- `TerrainConfig` + `generate_terrain()` — heightmap → mesh with computed normals.
- `BitmapFont` + `TextBatch` — monospace glyph atlas.
- `UiPanel`, `UiLabel`, `UiBatch` — screen-space overlay rendering.

#### Instanced Rendering + Compute + LOD

- `GpuParticleSystem` — GPU-driven particle simulation.
- `LodChain`, `TerrainLod` — distance-based mesh/resolution selection.
- `RenderGraph` — topological pass ordering with cycle detection.

- Cycle detection in render graph topological sort.
- Division-by-zero guards on all projection/transform functions.
